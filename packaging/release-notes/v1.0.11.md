## Fixed

- **The extension stayed on the old version.** The folder your browser loads
  is a copy, and it was only rewritten in a start-up step that does nothing on
  a machine that installs to the same place twice. It is now written on every
  launch, compared by content rather than by timestamp, and files an older
  version left behind are removed. Reload it in your browser once after
  updating and it will be the current one.
- **The extension threw on every tab close.** `badgeDueAt is not defined` —
  a leftover reference in two handlers, which meant everything after it in
  those handlers never ran.
- **A download could still be announced under the wrong name.** On Windows the
  browser hands over a name of its own, and for addresses ending in an
  identifier that name is the identifier. It is now checked the same way as
  any other guess.
