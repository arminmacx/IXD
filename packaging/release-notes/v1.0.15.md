## Fixed

- **The extension folder now lives beside the application.** It was being
  written to `%APPDATA%\IXD`, which belongs to no install in particular — so a
  portable copy and an installed copy shared one folder, and an update could not
  reach the path your browser was pointed at. It sits inside the installation
  now whenever that folder is writable, which means an update replaces it in
  place and you only have to reload the extension in your browser.
- **An update no longer removes it on the way past.** The folder is generated,
  so it is in no archive, and the step that clears out what a new version does
  not ship was deleting it.

## Added

- **The Windows installer asks who it is for.** *Everyone* needs administrator
  and installs to `Program Files`; *just me* needs nothing and installs to
  `%APPDATA%\IXD`. Both get Start menu and desktop shortcuts, an Add/Remove
  Programs entry, and an uninstaller.
- **An installer on every platform.** `setup.exe` on Windows, a `.pkg` on macOS
  beside the existing `.dmg`, and the `.deb` on Linux. The self-updating
  portable archives are still published alongside all of them.
