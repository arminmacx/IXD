## Fixed

- **The extension is installed where you installed the app.** The installer now
  writes the extension folders into the folder you chose, with the rights to do
  it. Before, the application created them at startup wherever that particular
  launch happened to be allowed to write — which on an all-users install meant
  one folder the first time and a different one ever after, so the browser kept
  loading a version that never changed.
- **Installing no longer leaves the app running as administrator.** Ticking
  "Start Internet Xtreme Downloader" on the last page of the installer ran it as
  a child of the installer, so it inherited administrator rights for the rest of
  the session. It now starts as you.
