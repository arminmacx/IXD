> ### Updating from 1.0.16 or 1.0.17? Download the installer below and run it.
>
> Those two versions cannot update themselves — that is the defect this release
> fixes, and a build carrying it cannot fetch its own fix. Run
> **`ixd-1.0.18-windows-x64-setup.exe`** over your existing install: same
> folder, same choice of *just me* or *everyone*, and your settings and
> downloads are kept. From this version on, updating happens inside the app.
>
> Portable copies and the `.deb` are unaffected.

## Fixed

- **An installed copy can update itself again.** Installed from `setup.exe`,
  the update window said *"this build was installed from a package"* and
  offered only a link to the download page — the Download and install button
  was not there at all. It now downloads the new installer and runs it, which
  upgrades in place and keeps your shortcuts, your uninstaller and the version
  Windows shows in Add/Remove Programs.

  Two things caused it: the installer packed a build that carried no marker
  saying how it updates, and the check additionally demanded write access to
  the install folder — which an all-users install in `Program Files` never
  grants to the person running the application.
