## Fixed

- **The app now tells you when there are two copies of it on this machine.**
  One installed by `setup.exe` and one unpacked from the portable zip update
  separately, and the browser keeps loading the extension from whichever it was
  pointed at first — which looks like an extension stuck on an old version. The
  Log now names both locations and says which one the browser is reading.
- **The quality row waits until there is something true to say.** It reads
  "Getting info from server…" while the page is read, then shows the quality
  actually chosen, instead of naming a quality before anything has been read.

If you have both an installed copy and a folder unpacked from the `.zip`,
remove the one you do not want. **Install `…-windows-x64-setup.exe`** — the
`.zip` is the portable copy and unpacks to a folder called `ixd`, which is how
a second installation appears in `Downloads`.
