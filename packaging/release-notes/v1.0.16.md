## Fixed

- **The extension folder is with the application on every platform now.** macOS
  was still putting it in the data directory; it goes beside the `.app` — the
  folder you extracted into — as it already did on Windows and Linux. A portable
  copy that updates itself replaces that folder in place, so the path you
  pointed your browser at keeps working and only needs a reload.
- **A folder left behind by 1.0.14 or earlier is now removed.** It was never
  refreshed again, so a browser still loading from `%APPDATA%\IXD\extension`
  was stuck on an old extension no matter how many times you updated. The Log
  names the folder it removed and where to point your browser instead.
- **The installer called itself `ixd`.** Add/Remove Programs, the Start menu
  folder and the desktop shortcut used the internal short name instead of
  *Internet Xtreme Downloader*. Only the display names change, so 1.0.15
  upgrades in place.

An all-users install still keeps the extension in the data directory: nobody
running the application can write to `Program Files`. Start-up now says in the
Log which folder it used and why.
