## Fixed

- **The Settings button could be pushed off the toolbar.** On a narrower window
  it moved into the overflow menu and you had to resize to get it back. The
  toolbar gives up words now instead of buttons — the search box narrows, then
  the right-hand buttons show their symbols with the name in the tooltip — so
  every button stays where it is at any window size or font scale.
- **Clicking the "download complete" notification opens the folder.** It now
  shows the finished file selected in its folder, rather than doing nothing.
- **The browser extension no longer logs `Cannot create item with duplicate id`.**
  Two menu rebuilds could overlap after a browser restart.
- **A build that cannot update itself points at the right file.** Instead of
  opening a release page with thirteen files on it, the button downloads the
  one this platform needs and says so.

If you are still on 1.0.16 or 1.0.17 on Windows, download the installer below
and run it over your existing install — those versions cannot update
themselves, which 1.0.18 fixed.
