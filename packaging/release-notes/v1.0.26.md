## Fixed

- **Updating an installed copy no longer fails with "requires elevation".** The
  installer was started by a call that cannot raise the Windows permission
  prompt, so an all-users install reported `[WinError 740]` at the end of every
  download and installed nothing. It now asks for permission properly.
- **An interrupted update is resumed, not downloaded again.** If the connection
  drops, the next attempt continues from where it stopped, and a file that is
  already complete is not fetched a second time.
