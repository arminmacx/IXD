## Fixed

- **Signing in no longer starts downloads you did not ask for.** If IXD starts
  with Windows, logging in could begin a pile of old downloads at once — some
  of them weeks old. Anything ever left waiting its turn stayed queued for
  good, and every launch picked the whole lot back up. They are paused at
  startup now: still in the list, still at the byte count they reached, waiting
  for you to start them.
- **A `.exe` from the browser lands in Programs.** Every download handed over
  from a page went to the top of the download folder instead of its category
  folder. The folder box shows where the file is really going, and follows a
  corrected filename.
- **A second download from the same page opens its own window.** The two used
  to land exactly on top of each other, so it looked like one window that had
  ignored the second click. They cascade and flash in the taskbar.
- **Updating no longer stops at "ixd is running".** The installer now closes the
  running copy itself instead of asking you to retry.
- **A build that cannot update itself points at the right file.** The button
  downloads the file this platform needs rather than opening a release page
  with thirteen files on it.
