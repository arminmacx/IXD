## Fixed

- **No progress bar on the Windows taskbar.** `ULONGLONG` does not exist in
  `ctypes.wintypes`, so the import failed and the whole feature was dead. It
  had never worked on Windows.
- **No application icon on Linux.** The per-user icon directory had no
  `index.theme`, so the desktop never searched it and could not resolve the
  name the window carries.

## Added

- **Launch at startup**, minimised to the tray. Settings → General.
- **A splash while the app starts**, naming what it is doing.

The Windows fix is untested on Windows hardware. If the taskbar bar is still
missing, the Log says why.
