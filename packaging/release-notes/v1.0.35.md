## Fixed

- **Downloads from servers that advertise resume support and do not have it.**
  Some hosts answer with `Accept-Ranges: bytes` and then send the whole file
  back for every part that is asked for — `install.gameforge.com` is one — and
  the download failed with "server ignored the Range header". Range support is
  now confirmed before the connections are planned, and a host that only
  reveals the lie mid-transfer no longer ends the download: it restarts on a
  single connection and finishes.
