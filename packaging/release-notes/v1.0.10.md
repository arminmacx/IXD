## Fixed

- **The updater could not find the file it was looking at.** On Windows a
  1.0.8 or 1.0.9 build reported that the release "publishes nothing this build
  can use" and then listed the archive it wanted. The Windows archive has the
  version in its name, and each build recorded that whole name as the file to
  look for — so it searched a newer release for an older release's filename.
  It now looks for the shape of the file rather than one release's name of it,
  and falls back to the platform's archive if anything is missing.

## If you are on 1.0.8 or 1.0.9

Install this one by hand — the broken lookup lives inside those builds, so
they cannot fetch the fix themselves. From 1.0.10 onwards, updating is
automatic again.

Reload the extension in your browser afterwards.
