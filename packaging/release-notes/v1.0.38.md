## Fixed

- **Reading the qualities off a page is many times faster, on every site.**
  Every request opened its own connection and negotiated its own encryption,
  and reading a page's qualities takes several requests — so most of the wait
  was setting up connections that were then thrown away. Connections are reused
  now. Measured against a real site: five requests took 20.6 seconds before and
  1.9 seconds after.

This one change touches everything the application downloads, so it ships on
its own.
