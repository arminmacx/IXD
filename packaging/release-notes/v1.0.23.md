## Fixed

- **The "download complete" notification opens the file's folder again.** It
  was opening Documents instead. Any filename with a space in it — which is
  most of them — was being passed to Explorer in a form it could not read, so
  it fell back to its default folder.
- **A download started from the browser gets its own window.** Clicking a link
  in a page opened the file-info window, and pressing Start put the transfer
  straight into the main list with no progress window of its own, unlike a link
  added by hand.
