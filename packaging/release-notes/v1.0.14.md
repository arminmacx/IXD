## Fixed

- **"This extension is corrupted", and the folder had no manifest in it.** The
  file your browser actually reads was being written and then deleted again on
  every launch, so the folder you were pointed at held everything except the
  one file that makes it an extension. It is written as the folder is created
  now, and start-up says in the Log whether it is there. Remove the broken
  entry in your browser and load the folder again.

## Added

- **Firefox gets a folder of its own.** The two browsers need different
  manifests under the same filename, so `extension-firefox` sits beside
  `extension` and each one is loadable as it stands.

  | | Chrome / Edge / Brave | Firefox |
  |---|---|---|
  | Linux | `~/.local/share/ixd/extension` | `~/.local/share/ixd/extension-firefox` |
  | Windows | `%APPDATA%\IXD\extension` | `%APPDATA%\IXD\extension-firefox` |

- **A Windows installer.** Start menu and desktop shortcuts, an entry in
  Add/Remove Programs, and an uninstaller. It installs for you alone, under
  `%LOCALAPPDATA%\Programs\IXD`, and never asks for administrator. The portable
  zip is still published beside it.
