## Fixed

- **Looking at an update no longer installs it.** Opening the update window ran
  the same check the daily one does, and that check was what started an
  unattended install — so reading what was available and closing the window
  without pressing anything installed it anyway a few minutes later. A check
  you asked for now reports and nothing else. "Install it by itself" still
  works, from the daily check, and the Log says when it is about to.
- **Settings → Updates → Check now works.** It failed with an error the moment
  the update window closed.
