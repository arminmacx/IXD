## Fixed

- **The quality menu could break on sites whose streams it had to read from the
  player.** An error introduced in 1.0.37 stopped the menu drawing on pages
  where the fallback list was the only thing to show.
- **Every HLS site shows sizes beside the resolutions**, and the download panel
  no longer says "size not published" for them. Live streams still show no
  size, because a live playlist only describes the last few seconds.
- **The menu is headed by the page's name** instead of a playlist filename like
  `1909970769.M3U8`.

## Added

- **Twitch clips.** They offer every quality with an exact size, instead of
  falling back to whatever the browser happened to load.
