## Added

- **It tells you when there is a new version.** A line appears at the foot of
  the window with the version number; clicking it shows what changed. Settings
  → **Updates** has a checkbox for the automatic daily check and a **Check
  now** button for doing it by hand.
- **A build that installs its own updates.** Alongside the usual downloads
  there is now one extra archive per platform, named `-selfupdate`. Run from
  that one and the update dialog downloads the new version and restarts into
  it. The `.deb`, the `.dmg` and the ordinary portable archives behave exactly
  as before: they tell you, and you install the new one the way you installed
  this one.

Whichever you use, **reload the extension in your browser afterwards** — the
new version writes it out again, but the browser keeps running the copy it
already loaded.

## Note

The check is one HTTPS request to this project's release page. It sends
nothing about you or about what you download, it follows the proxy configured
under Network, and it can be switched off.
