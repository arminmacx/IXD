## Fixed

- **The extension is updated where the browser is actually reading it.** On an
  all-users install the extension could end up in two folders — one written by
  a launch that had administrator rights, one by every launch after it — and
  the browser kept loading the stale one. It reported an old version through
  an update and through being removed and added again. There is one folder
  now, and if an old copy is left somewhere the Log names it and says where to
  point the browser.
- **The Windows build script runs to the end.** It lost a status line to
  `The system cannot find the batch label specified`.
