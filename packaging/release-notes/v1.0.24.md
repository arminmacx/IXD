## Changed

- **Updating no longer walks you through the installer.** It installs quietly
  in the mode you originally chose and reopens the application, the way it used
  to. An all-users install still asks Windows for permission once.
- **The tray icon shows a dot when a new version is available**, so an update
  found by the automatic check is visible without opening anything. The tray
  menu names the version, and clicking it opens the update window.
