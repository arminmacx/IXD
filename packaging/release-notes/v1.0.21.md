## Fixed

- **The quality shown for a YouTube video is the one you are getting.** The
  file-info window was showing the quality the extension *asks* for — 1080p
  unless you change it in the extension's options — so a 144p video announced
  itself as 1080p. It now says "up to 1080p" while it reads the page, then
  replaces that with the quality actually chosen.
- **No more `IXD-update` folder next to the installation.** Updating left the
  downloaded installer — about a hundred megabytes — in a folder beside the
  application that nothing ever cleaned up. Installed copies keep it out of
  `Program Files` entirely now, and a folder left by an earlier version is
  removed on a later start.
- **The log says which version of the extension is on disk.** A browser reads
  an unpacked extension when it starts, so it keeps reporting the previous
  version until you reload it from the extensions page. The log now names the
  version in the folder and says so.
