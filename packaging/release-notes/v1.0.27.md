## Fixed

- **Signing in no longer reopens a download you paused.** The browser announces
  the downloads it restores at start-up the same way it announces one you just
  clicked, and the extension could not tell them apart — so the file-info
  window came up asking where to put something you had already parked. A
  download the browser is picking back up is now left to the browser.
- **The downloaded update file is deleted once it has been installed.** It was
  kept for an hour after the update, and the app restarts inside that hour, so
  every update left its installer behind — a day of several updates left
  several of them.
