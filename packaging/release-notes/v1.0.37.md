## Fixed

- **A quality marked "mp4" now produces an MP4.** Clicking "160p · mp4" in the
  hover panel downloaded a `.ts`: the row was not asking for the container it
  was advertising, so the file was named after the segments the site serves.
  The container the row offers now travels with the click, and the transport
  stream is rewrapped as before.
- **The file-info window shows the size before the download starts.** It said
  "size not published" while the panel beside it displayed the size of the very
  stream being queued.
- **The panel stops repeating itself.** "Playing on this page" listed the
  playlists the site's player had fetched — twice each, above the real quality
  menu, labelled with the size of the playlist text rather than the video's.
  They are shown now only when there is no proper menu to show instead.
