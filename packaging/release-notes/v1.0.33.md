## Added

- **The Windows installer notices a copy already installed the other way.**
  Choosing "just me" when it is already installed for everyone — or the
  reverse — used to go through and leave two copies on the machine, sharing one
  settings file and one browser registration. It now says where the other one
  is and offers to remove it and carry on, install into it instead, or go back.

Updating from inside the application is unaffected: it never asks anything.
