## Fixed

**Quitting leaves nothing running (Windows).** `ixd.exe` stayed in Task Manager
after quitting, and only removing the extension stopped it. That process was
the browser's relay, not the application. The extension now closes it when it
has nothing to send.

**Progress shows on the Windows taskbar.** It was being drawn on the main
window, which is hidden when the browser starts IXD or you close it to the
tray. It now draws on whichever window is on the taskbar.

Neither is tested on Windows hardware. If the taskbar bar is still missing, the
Log records why.
