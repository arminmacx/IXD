## Fixed

- **Quitting left `ixd.exe` in Task Manager (Windows).** That process was the
  browser's native messaging relay, not the app. The extension now closes it
  when it has nothing to send.
- **No progress bar on the Windows taskbar.** It was drawn on the main window,
  which is hidden when the browser starts IXD or you close it to the tray. It
  now draws on whichever window is on the taskbar.

## Added

- **Launch at startup**, minimised to the tray. Settings → General.

The Windows fixes are untested on Windows hardware. If the taskbar bar is still
missing, the Log now says why.
