## Fixed

- **"The update did not finish — process … is still running."** The old
  version now closes properly when an update is ready: the window goes, the
  database is closed and the process ends, so the updater has the screen to
  itself until the new version starts. If it still will not go, the updater
  closes it rather than giving up.
- **A portable copy kept its update somewhere else.** Updates were unpacked
  under `%APPDATA%\IXD`; they are now unpacked beside the application, where
  you put it.
