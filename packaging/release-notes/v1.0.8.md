## Changed

- **Updating asks nothing of you.** On a `-selfupdate` build the new version
  downloads, the application closes, a small updater window replaces it and
  starts it again — no clicking through a dialog, no launching it yourself.
- **Settings → Updates can do it unattended.** Tick *Install it by itself and
  restart* and a new version is fetched and installed on its own. It waits
  until nothing is downloading first, so an update can never interrupt a
  transfer.

Reload the extension in your browser after an update — the new version writes
it out again, but the browser keeps running the copy it already loaded.
