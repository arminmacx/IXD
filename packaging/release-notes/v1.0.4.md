## Fixed

- **Downloads from GitHub arrived named after a UUID, with no extension.**
  A release asset redirects to an address ending in
  `74709710-bf21-4cd4-926a-526ff561a1bb`, and that address was taken as the
  filename even though the server had said `filename=ixd_1.0.4_amd64.deb` all
  along. What the server calls a file now wins over what its address looked
  like — on every site, not only GitHub. A name you typed yourself is still
  never overruled.

## Added

- **The scheduler ends with a choice.** When every download has finished,
  IXD can quit, sleep, hibernate or shut the machine down. Settings →
  Scheduler, or the new **Scheduler** button on the toolbar. It happens once,
  counts down first, and the countdown can be called off from the window;
  a paused or unfinished download counts as work outstanding, so it will not
  fire while one is waiting.
- **The scheduler has a button of its own** — which downloads a queue runs,
  the order they run in, and when it starts and stops, without going through
  Settings to find it.

Update the extension along with the application: reload it from your browser's
extensions page after the first launch of this version.
